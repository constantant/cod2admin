# CoD2 Admin — Mini App для управления сервером

Краткое описание для владельца сервера · обновлено 2026-09-08
(полная техническая версия: `PLAN-miniapp.md`; это дополнение к боту из `PLAN.md`/`PLAN-ru.md`)

Это **план, ещё не реализован** — описывает, что добавится к уже работающему боту.

## Что это

Сейчас ботом управляют командами в чате Telegram. Добавляем **Mini App** — полноценное
приложение прямо внутри Telegram (открывается кнопкой, не отдельная программа), с обычным
графическим интерфейсом вместо команд. Работает **вместе** с текущим ботом, не вместо него:
оба используют одну и ту же базу данных и один и тот же журнал действий — что бы вы ни сделали
в чате или в приложении, видно в обоих местах одинаково.

Что умеет:

1. **Полное управление RCON** — список игроков, кик/бан/разбан/врем.бан, смена карты — одним
   нажатием, вместо команды на каждое действие.
2. **Чат с игроками** — видно, что пишут в игровом чате, и можно писать в ответ прямо из
   приложения, не заходя в консоль сервера.
3. **Управление банами** — список забаненных игроков и IP, поиск, изменение причины/срока
   бана, снятие бана — с удобным просмотром, а не только через команды.
4. Дополнительно предложено (не обязательно для первой версии): панель со статистикой сервера,
   очередь необработанных жалоб `!report`, визуальное управление админами и ролями, заметки
   на подозрительных игроков, готовые шаблоны причин бана.

## Что для этого понадобится

Telegram требует, чтобы такое приложение открывалось по **защищённому адресу (https)** с
настоящим сертификатом — тут не обойтись без него, в отличие от самого бота.

- Для типичного случая (сервер арендован у хостера и уже имеет "белый" IP-адрес, как обычно
  и бывает у игровых серверов) — это решается автоматически при установке: адрес и сертификат
  настраиваются сами, отдельно покупать домен не обязательно (есть бесплатный вариант — адрес
  вида `185-158-113-146.nip.io` сам указывает на ваш IP).
- Если сервер стоит дома за роутером без белого IP — потребуется дополнительная настройка
  (бесплатный туннель Cloudflare); этот вариант **не** делается автоматически установщиком —
  описан отдельно в документации как ручная настройка для такого редкого случая.
- Вход в приложение — через ваш Telegram-аккаунт автоматически, отдельный пароль не нужен;
  доступ получают только те, у кого уже есть роль админа/модератора в боте.

## Решено

- Установщик сам, без лишних вопросов, настраивает бесплатный адрес (nip.io), если владелец не
  указал свой домен — не нужно каждый раз спрашивать домен при установке.
- Первая версия ограничивается одним сервером (как когда-то и сам бот начинался с одного
  сервера) — переключатель между несколькими серверами добавится позже, на последнем этапе.

## Пока не решено

- Часть доп.функций (очередь жалоб, статистика) потребует новых таблиц в базе данных —
  решится по ходу разработки, не блокирует остальное.
- Тестовая среда автора плана (NAS) никогда не станет реальным сервером, это просто стенд для
  разработки и проверки — не показатель того, как будет выглядеть установка у реального
  владельца сервера.

## Порядок работ

1. Базовый каркас приложения (авторизация через Telegram, простая проверка на связь с ботом) —
   пока на один сервер, без переключателя между серверами.
2. Управление RCON (список игроков, кик/бан/смена карты).
3. Чат с игроками (просмотр и отправка сообщений).
4. Управление банами (поиск, редактирование, снятие).
5. По желанию, позже — переключатель между несколькими серверами, панель статистики, очередь
   жалоб, визуальное управление ролями и остальные доп.функции.
6. Отдельно, не блокирует разработку — настройка HTTPS-адреса при установке на реальном сервере.

Первые шаги (каркас и RCON-управление) можно делать и проверять локально ещё до того, как
решится вопрос с адресом/сертификатом для реального сервера.
