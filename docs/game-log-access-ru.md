# Как подключить лог игрового сервера к боту

Карточкам `!report` и чату в Mini App нужно, чтобы бот читал `games_mp.log` как локальный файл.
По RCON лог получить нельзя. Все остальные команды работают и без него.

## Как подключить

Владелец отправляет боту `/findlog` (для конкретного сервера — `/findlog --server <алиас>`). Бот сам
находит лог и начинает его читать, перезапуск не нужен. Чтобы приходили карточки `!report`,
отправьте ещё `/bindserver <алиас> private` в группе админов.

Если подключить лог не получилось, бот напишет, что делать. Ниже — все возможные случаи.

## Бот не может прочитать файл

Бот пришлёт команды с вашим точным путём. Выполните их на сервере от root. Пример для
стандартного пользователя бота:

```sh
setfacl -m u:cod2admin:x /home /home/cod2 /home/cod2/main
setfacl -m u:cod2admin:r /home/cod2/main/games_mp.log
setfacl -d -m u:cod2admin:r /home/cod2/main
```

- Первая строка разрешает боту проходить через каждую папку.
- Вторая разрешает читать сам файл.
- Третья сохраняет доступ, если сервер создаст файл заново.

Доступ получает только пользователь бота. Если команды `setfacl` нет, установите пакет `acl`.

## Бот не находит файл, а игровой сервер на этой же машине

Бот не может искать в папках, которые ему закрыты. Найдите лог от root:

```sh
find / -name games_mp.log 2>/dev/null
```

Затем отправьте боту `/findlog <найденный путь>`, и он пришлёт команды из раздела выше.

## Игровой сервер работает в Docker

Лог должен быть файлом на самой машине, поэтому его папка должна быть подключена как bind mount, а
не как именованный том. Сервер пишет лог в `<fs_homepath>/main/games_mp.log`, так что подключите
`fs_homepath` к папке на машине.

## Бот работает в контейнере

Бот видит только те папки, которые подключены к контейнеру. Подключите папку с логом только для
чтения (`/путь/на/машине/main:/cod2-logs:ro`), пересоздайте контейнер и отправьте `/findlog`.

Затем на самой машине сделайте лог доступным для чтения: `chmod o+r games_mp.log` и `o+x` для его
папки и всех папок выше. Учтите, что читать лог смогут все пользователи этой машины.

Для набора Docker из `installer/docker` укажите папку при запуске `run.sh`, см.
`installer/docker/README-ru.md`.

## Игровой сервер на другой машине

Оттуда бот лог прочитать не может. Установите бота на машину с игровым сервером. Без лога работает
всё, кроме `!report` и чата в Mini App.

## Сервер не пишет лог

Укажите в его конфиге `g_log "games_mp.log"` и `g_logsync "1"` и перезапустите сервер.
