# Известные игроки — ник + сети провайдера (кратко)

Статус: реализовано 2026-11-09 (ветка `feat/known-players`), на живом сервере ещё не проверялось.
Подробности — в `docs/PLAN-known-players.md`.

**Идея.** Админ ведёт список «известных игроков»: ник и сети провайдеров (ASN), из которых этот
человек обычно играет. Бот сверяет всех игроков на всех серверах:

- ник из списка и ASN из его списка — «свой»: его не кикают за VPN (`/vpnkick`);
- ник из списка, но ASN не из его списка — кик сразу при входе (только кик, без бана: владелец мог
  сменить провайдера, тогда админ добавляет ему сеть);
- ника нет в списке — бот его не трогает.

ASN берётся из уже загруженной базы DB-IP (та же, что у `/vpnnets`). Если ASN определить нельзя
(база не загружена, локальный адрес), игрока не кикают.

**Что не меняется.** Баны и муты действуют как раньше: список лишь отключает автоматические кики.
Права — те же, что у `/vpnkick` (`vpn`). Включается командой `/known on`, по умолчанию выключено.

**Управление.** В Telegram: `/known`, `/known add <ник> [AS12389 …]` (без ASN берёт сеть игрока,
который сейчас на сервере), `/known addasn`, `/known removeasn`, `/known note`, `/known remove`.
В Mini App: «Ещё → Известные игроки». В `/players` у известного игрока ✅, у известного ника с чужой
сети ⚠️. Строка в игровой чат при таком кике — `known_kick` в `/templates` (сначала пустая).

**Ограничения.** ASN — это только провайдер: человек у того же провайдера с тем же ником пройдёт.
Двое с одним ником делят одну запись. База DB-IP Lite обновляется раз в месяц, поэтому после
обновления кого-то могут ошибочно кикнуть — лечится `/known addasn`.

**GUID.** У записи могут быть и настоящие GUID (у большинства игроков он 0, поэтому база — ASN).
GUID из записи подтверждает игрока с любой сети. Другой настоящий GUID у ника из списка кикают
даже при «своей» сети (новый CD-key — новый GUID, админ добавляет его через «Отметить как
известного»). Кнопка «Отметить как
известного» и `/known add` сохраняют настоящий GUID вместе с ASN.
