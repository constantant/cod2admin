# Что нужно на сервере для установки бота (со всеми функциями и Mini App)

Коротко: нужен root (или `sudo`) на машине с Debian/Ubuntu или Alpine — лучше всего на той же,
где работает игровой сервер, — и открытые порты 80 и 443, если нужен Mini App. Root требуется
только для установки и повторного запуска установщика; сам бот работает от непривилегированного
пользователя `cod2admin`.

## На машине

- **Root-доступ по SSH.** Без него установщик не запускается. Он ставит пакеты (Node.js,
  PostgreSQL, `sudo`, Caddy), создаёт пользователя `cod2admin`, пишет в `/opt/cod2admin`,
  регистрирует службу systemd/OpenRC и добавляет одно узкое правило sudoers, чтобы команда
  `/update` из Telegram могла ставить новую версию.
- **Дистрибутив.** Только Debian/Ubuntu или Alpine. Caddy берётся из системных пакетов — он есть
  в Debian 12+, Ubuntu 22.04+ и Alpine.
- **Настоящая VM или выделенный сервер, а не игровая панель.** Хостинг, где есть только FTP и
  веб-консоль, не подойдёт.

## От игрового сервера

- **RCON:** `rcon_password` и адрес/порт. Этого достаточно для кика, банов, смены карты, списка
  игроков и страницы банов.
- **Чтение файла `games_mp.log`.** Нужно для `!report`, отслеживания входов/выходов и живого чата
  в Mini App. Поэтому бота лучше ставить на машину с игровым сервером. Установщик проверяет
  только, что файл читается от root, а бот работает от `cod2admin` — убедись, что этот
  пользователь может прочитать файл и пройти по папкам выше него.

## Сеть

- **Входящие порты 80 и 443 (TCP) из интернета** — только для Mini App. Telegram открывает его
  исключительно по HTTPS, сертификат Caddy получает сам. В `ufw` установщик откроет порты сам;
  в файрволе панели хостинга их нужно открыть вручную.
- **Публичный IP.** С ним используется бесплатное имя `<ip>.sslip.io`, свой домен не нужен
  (но можно указать и свой).
- **Если порты 80/443 уже заняты nginx или Apache:** Caddy не ставится, а в свой веб-сервер нужно
  добавить правило проксирования, которое напечатает установщик.
- **Исходящий HTTPS:** к GitHub (релизы и обновления), зеркалам пакетов и Telegram. Из России бот
  сам переключается на встроенные релеи для Telegram — настраивать ничего не нужно.

## Из Telegram

- Токен бота от @BotFather.
- По желанию — числовой Telegram ID владельца. Если его не указать, установщик напечатает код
  `/claim`, который нужно отправить боту.

## Важно для сервера в России

Связь бота с Telegram обеспечивают релеи, но каждому админу всё равно нужен свой способ открыть
Telegram на телефоне (VPN или прокси) — иначе не получится пользоваться ни ботом, ни Mini App.

## Установка

```sh
curl -s https://api.github.com/repos/constantant/cod2admin/releases/latest \
  | grep browser_download_url | grep -v gateway | cut -d '"' -f 4 | xargs curl -LO
tar -xzf cod2admin-*.tar.gz
cd cod2admin-*/
sudo ./install.sh
```

Установщик задаёт вопросы по ходу и сразу проверяет ответы (токен бота, RCON).
