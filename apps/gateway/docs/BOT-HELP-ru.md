# cod2admin бот — помощь

Этот бот управляет сервером Call of Duty 2 и позволяет игрокам жаловаться на нарушителей прямо
из игрового чата. Отправьте `/help` для этой же инструкции на английском.

## Как пожаловаться на игрока (может любой, прямо в игре)

Напишите в обычном игровом чате (или командном чате): `!report <имя> <причина>`

Пример: `!report Cheatr123 aimbot`

- `<имя>` не обязательно писать точно — достаточно узнаваемой части (регистр не важен).
- `<причина>` необязательна, но помогает админу быстрее принять решение.
- Если вы не можете прочитать или набрать имя (например, оно на незнакомой раскладке), просто
  напишите что-нибудь вместо имени и опишите ситуацию словами — команду, счёт, оружие, время —
  админ сможет найти нужного игрока по этому описанию.
- Сообщение появится здесь, в этом чате, в виде карточки, с которой админ может сразу принять
  меры. Повторные жалобы на одного и того же игрока подряд ограничены по частоте.

## Команды для любого из персонала

Их может использовать любой из списка персонала, в том числе без прав (`none` в `/listadmins`).
Владелец может использовать все команды ниже.

- `/status` — название сервера, карта, количество игроков
- `/players` — подробный список игроков с их IP-адресами, страной и провайдером (🛡 — IP от VPN,
  прокси или Tor)
- `/servers` — список серверов, которыми управляет этот бот
- `/app` — открывает приложение для управления сервером прямо в Telegram (игроки, чат, жалобы,
  заметки, карты, баны), если владелец бота его включил. В личном чате с ботом его открывает и
  кнопка меню.
- `/mcp` — подключить свой ИИ, в личном чате с ботом. Адрес из ответа бота добавьте в
  приложение. Оставьте страницу в браузере открытой, нажмите «Approve in Telegram» (откроется
  рядом), выберите разрешение и вернитесь на страницу. Она вернёт вас в приложение. `/mcp`
  показывает подключения, `/mcp revoke <id>`
  отключает одно, `/mcp revoke all` — все. Приложение получает только те действия, которые вы
  разрешили и которые у вас всё ещё есть. Обновление бота, релеи Telegram, список персонала и
  добавление сервера остаются в этом чате

## Команды по правам

Для команды нужно право из заголовка. Эти права выдаёт `/permit`.

### `kick`

- `/kick <id или имя клиента> [--server <алиас>]`
- Кнопка Kick на карточке жалобы требует это право.

### `tempban`

- `/tempban <id клиента> [длительность] [причина] [--server <алиас>]` — длительность вида `30m`,
  `2h`, `7d`; если не указана — 30 минут по умолчанию. Банит по GUID игрока, если сервер его
  сообщает, иначе по IP.
- Кнопка Temp ban на карточке жалобы требует это право.

### `ban`

- `/ban <id клиента> [причина] [--server <алиас>]` — навсегда
- `/unban <guid-или-ip>` — снимает бан на всех серверах
- `/bans` — список активных банов по GUID и IP, с сервером, где был выдан каждый
  Баны (включая `/tempban`) действуют на **всех** серверах этого бота, а не только там, где
  игрока забанили, — `--server` лишь выбирает, на каком сервере искать игрока.
- Кнопка Ban на карточке жалобы требует это право. Resolve и Ignore доступны любому из персонала.

### `maps`

- `/map <название> [режим] [--server <алиас>]` — название сверяется с картами, установленными на
  сервере; при опечатке бот подскажет похожие. Режим (`ctf`, `tdm`, `dm`, `sd`, `hq` или режим
  мода) меняет и его, например `/map mp_toujane ctf`; без режима карта загрузится в текущем
- `/maps [--server <алиас>]` — кнопки для смены карты: сначала карты из ротации, затем все
  остальные карты, установленные на сервере. ⚠ — нестандартная карта: игроков, у которых её нет,
  может выкинуть, если сервер не раздаёт карты, поэтому бот сначала переспросит

### `say`

- `/say <сообщение> [--server <алиас>]` — отправляет сообщение в чат игрового сервера

### `servers.assign`

- `/bindserver <алиас>` — делает **этот** чат публичной группой сервера: сюда приходят итоги карт
- `/bindserver <алиас> private` — делает **этот** чат чатом админов сервера: сюда приходят карточки `!report`.
  В публичной группе (с публичным `@username` или уже привязанной как публичная) не сработает.
  Если публичной группы нет, итоги карт тоже идут в чат админов
- `/unbindserver <алиас>` — снимает привязку **этого** чата к серверу (публичной группы или чата админов)
- `/setdefault <алиас>` — на какой сервер идут команды без `--server`

### `vpn`

- `/vpnnets` — сети провайдеров, которые бот помечает как 🛡 VPN (для VPN, которых нет во
  встроенных списках). `/vpnnets add <IP игрока или ASN>` помечает всю сеть этого IP (например,
  IP игрока с VPN из `/players`); `/vpnnets remove <ASN>` снимает метку. Это только метка — за
  неё никого не кикают
- `/vpnkick on|off` — кикать игроков с меткой 🛡 сразу при входе, на всех серверах (по умолчанию
  выключено; никого не банит). Строка в игровой чат для этого кика задаётся через `/templates`
  и сначала пустая. `/vpnkick allow <GUID или имя>` —
  исключение для своего игрока, `/vpnkick unallow` — убрать его, `/vpnkick` — текущее состояние
- `/known` — известные игроки: ник, привязанный к сетям провайдеров (ASN), из которых играет его
  владелец. `/known add <ник> [AS12389 …]` (без ASN берёт сеть игрока, который сейчас на сервере),
  `/known addasn <ASN> <ник>`, `/known removeasn <ASN> <ник>`, `/known addguid <GUID> <ник>`,
  `/known removeguid <GUID> <ник>` (также `add <ник> AS1 guid:716922`; без них `add` берёт сеть и
  настоящий GUID игрока, который сейчас на сервере), `/known note <ник> <текст>`,
  `/known remove <ник>`. `/known on|off` (по умолчанию выключено): ник из списка с «своей» сети
  никогда не кикается за VPN; тот же ник с любой другой сети кикается сразу при входе (только
  кик, без бана). Баны и муты действуют как обычно. ASN говорит лишь о провайдере: человек у того
  же провайдера с тем же ником пройдёт; двое с одним ником делят одну запись. Строка в игровой чат
  для этого кика — `known_kick` в `/templates` (сначала пустая). Настоящий GUID (у большинства он
  0), сохранённый для ника, подтверждает игрока с любой сети; другой настоящий GUID у ника из
  списка кикают даже с «своей» сети (новый CD-key — новый GUID: добавьте его через «Отметить как
  известного»). В `/players`: ✅ известный,
  ⚠️ известный ник с чужой сети или с другим GUID

### `admins.manage`

- `/addadmin <telegram-id-или-ответ>` — ответьте на сообщение человека или укажите его числовой
  Telegram ID. Добавляет без прав (доступны только общие команды персонала выше). Если человек уже
  в персонале, его права не меняются — их меняет `/permit`
- `/permit <telegram-id-или-ответ> [kick, tempban, mute]` — заменяет набор прав. Идентификаторы
  разделяются запятыми или пробелами. Без идентификаторов список очищается. Если у человека уже
  есть `rcon` или `update` и вы их не указали, они сохраняются
- Выдать или забрать `rcon` и `update` может только владелец. Наличие этих прав не позволяет
  передать их дальше, а пропуск в списке их не снимает
- `/removeadmin <telegram-id-или-ответ>` — владельца и себя удалить нельзя. Любой с правом
  `admins.manage` может удалить остальной персонал
- `/listadmins` — все, у кого есть доступ. Владелец показан как `owner`. Остальные — списком прав
  или `none`

### `audit`

- `/auditlog [n]` — последние n действий (по умолчанию 10, максимум 50)

### `rcon`

- `/rcon <сырая команда> [--server <алиас>]` — отправляет что угодно напрямую в консоль сервера.
  Выдать или забрать это право может только владелец

### `servers.manage`

- `/addserver <алиас> <хост:порт> <rcon-пароль>` — добавляет ещё один сервер (или обновляет
  добавленный ранее). Отправляйте только в личном чате с ботом, не в группе: бот удаляет
  сообщение, потому что в нём пароль, и сохраняет сервер, только если тот ответил
- `/removeserver <алиас>` — убирает сервер, добавленный через `/addserver`

### `logs`

- `/findlog [--server <алиас>]` — находит `games_mp.log` сервера на машине бота и начинает его
  читать: это нужно для карточек `!report` и чата в приложении. Перезапуск не нужен.
  `/findlog <путь>` — использовать указанный файл, `/findlog off` — перестать читать лог. Если
  бот не может прочитать лог, он пришлёт команды, которые дают ему доступ

### `update`

- `/update` — ставит новую версию бота после вашего подтверждения; о выходе новой версии бот
  сам пишет владельцу. Выдать или забрать это право может только владелец

### `relays`

- `/relays` — как бот подключается к Telegram: напрямую или через релеи там, где Telegram
  заблокирован (например, серверы в России). `/relays test` проверяет все маршруты; `add <url>`,
  `remove <n>`, `direct on|off` и `reset` меняют список, сразу же

### `templates`

- `/templates` — строки, которые бот сам пишет в игру: кик, бан, временный бан, кик за VPN и
  предупреждение о заглушении. `/templates set <id> <текст>` меняет одну, `/templates clear <id>`
  ничего не отправляет, `/templates reset <id>` возвращает встроенную. Подстановки: `{name}`
  `{reason}` `{kind}` `{minutes}`. Строка кика за VPN пустая, пока её не зададут. Набранный
  `/say` к этим строкам не относится

## Права

Лестницы ролей moderator / admin / owner больше нет. У каждого из персонала свой набор
идентификаторов прав. Пустой набор — только чтение. У владельца есть все права, включая те, у
которых нет команды в чате: `mute`, `presets`, `cvars.read`, `cvars.write`, `servers.view`,
`notes.manage`. Они используются в приложении (`/app`).

Выдать или забрать `rcon` и `update` может только владелец. Остальные могут включать в набор
только те права, которые есть у них самих, и не могут впервые выдать `rcon` или `update`, даже
если сами ими обладают.

ИИ, подключённый через `/mcp`, может пользоваться только теми правами, которые вы разрешили
этому подключению, и только пока они у вас есть. `update`, `relays`, `admins.manage` и
`servers.manage` остаются в этом чате. Подключение только для чтения видит игровой чат. Разрешение
`say` на нём даёт говорить: в начале строки ваше имя, примерно раз в 10 секунд. Подключение,
которое может кикать, банить, менять карту или слать консольную команду, чат не получает.

## Как получить доступ

Если вас только что назначили владельцем бота через секретный код, напишите боту лично (не в
этом чате):

- `/claim <секрет>`

Всем остальным нужно, чтобы кто-то с правом `admins.manage` выполнил для них `/addadmin`, а затем
`/permit` с нужными правами.

## Длинные списки

Если ответ на `/players`, `/bans`, `/auditlog` или `/rcon` получается длинным, бот присылает
короткую сводку и прикладывает полный список файлом `.md` (текстовая таблица: IP, город,
провайдер, GUID, причины…). Его можно открыть любой программой для просмотра текста.

## Про несколько серверов

Большинство команд принимают необязательный флаг `--server <алиас>` в конце, если этот бот
управляет более чем одним сервером — список алиасов см. в `/servers`. Без флага команда идёт
на сервер, привязанный к этому чату (`/bindserver`, любой вид), иначе — на сервер по умолчанию
(`/setdefault`). Сервер из конфига бота нельзя изменить или удалить из Telegram.

Данные о местоположении и провайдерах IP: [DB-IP.com](https://db-ip.com) (CC BY 4.0). Диапазоны
VPN: X4BNet (github.com/X4BNet), выходные узлы Tor: Tor Project.
